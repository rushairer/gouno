# Contributing

Use Go 1.25 or a currently supported newer release. Before opening a pull
request, run `gofmt`, `go test -race ./...`, `go vet ./...`, golangci-lint, and
govulncheck. Commits use Conventional Commits and public behavior changes must
update README and CHANGELOG under `Unreleased`.

By contributing, you agree that your contribution is licensed under the MIT
License in this repository.
